# 素材インデックス

素材ファイルの「何が・どこに・どう引くか」だけを書く。内容は複製しない（複製すると陳腐化する）。
プロジェクトルート（`entry_sheet.md` があるディレクトリ）を基準にする。

- 燈株式会社: 散文の中では「スタートアップ企業」「開発アルバイト」、経歴列挙型の設問では実名。迷ったらユーザーに確認。

- 見出し: 企業は `## 企業名`（既存の DeNA・チームラボ・MIXI は `#`）。設問は企業の1つ下のレベル。設問見出しは原文＋`（N字以内）`。

## エピソード使用マップの引き方

静的な表は置かない（追記のたびに陳腐化する）。毎回これを実行する:

```bash
python3 .claude/skills/es-coach/scripts/es_index.py --episodes            # 企業 × エピソード
python3 .claude/skills/es-coach/scripts/es_index.py --episodes --company MIXI   # 1社で使用済みのもの
```

タグの定義は `scripts/es_index.py` の `EPISODE_TAGS` が正典。

2026-09-14 時点の傾向（参考。最新は上のコマンドで確認）:
- iPhone 対応が7社で最頻出、家族フィードバック（mecap）と React/FastAPI 適応も7社。使い回し感が出やすい。
- 「タスク約1か月短縮」は企業別回答で未使用。「実装速度30〜40%向上」は MIXI のみ。
- 研究（対話ロボット）は GREE のみ。
