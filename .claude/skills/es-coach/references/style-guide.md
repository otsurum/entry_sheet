# 文体ガイド

過去 ES（343文）を分析して決めた、この人の文章の「良いところを残し、癖を抑える」ためのルール。

## 基本

- です・ます調で統一。体言止めは箇条書きの中だけ。
- 一文は 80 字以内を目安、100 字を超えたら分割する。過去回答の一文は中央値 62 字だが、上位1割が 122 字超で、そこが読みにくさの原因。
- 1段落1役割。段落の間は空行1つ（entry_sheet.md の慣習）。400 字なら3段落、500〜600 字なら3〜4段落。
- 結論ファースト。冒頭1文で設問に答える定型: 「私の強みは〜です」「〜に挑戦したいです」「志望理由は〜です」「一番成長した経験は〜です」。
- 主語は「私は」を省いてよいが、チームの成果と自分の行動は区別する（「チームで〜した。その中で私は〜を担当した」）。

## 箇条書きを使う／使わない

- 使う: 設問が【見出し】形式を指定している（MIXI 型）、プロダクト説明、経歴・イベントの列挙、逆質問。
- 使わない: 志望動機、自己PR、ガクチカ、研究内容、キャリアビジョン。散文で「なぜ」を書く設問は箇条書きにすると根拠が消える。

## 口癖の上限（回答1本あたり）

過去回答で頻出し、複数回出ると文章が単調になる語。

| 語 | 上限 | 言い換え例 |
|---|---|---|
| 単なる／単に（「単なる〜ではなく」構文） | 合計1回 | 「〜にとどまらず」「〜で終わらせず」、または構文自体を外して肯定文で書く |
| だけでなく | 1回 | 「〜に加えて」「〜も」 |
| と考えています | 1回 | 「〜したいです」「〜と実感しました」「〜に取り組んでいます」「〜だと学びました」 |
| 設計思想 | 1回 | 「設計方針」「既存の設計」「責務分離の考え方」 |
| 認知負荷 | 1回 | 「読み手の負担」「レビューの手間」 |
| 痛感しました | 1回 | 根拠を添える（何が起きて、何に気づいたか） |

## 削除候補の誇張副詞

飛躍的、劇的、徹底的、大幅に、極めて、非常に、圧倒的。
数値があれば副詞は不要。数値が無いなら副詞を消して事実だけ書く（「レビュー時間が減った」）。

## 「貴社」

0〜1回。原則は社名を直書きする（サイボウズ、pixiv、MIXI の過去回答がこの形で、具体的に読める）。ただし提出フォームの注意書きで「貴社」表記を求められている場合はそれに従う。

## 削る優先順位（文字数超過のとき）

上から順に削る。下に行くほど内容が減るので、上で収まればそこで止める。

1. 誇張副詞・強調語（「非常に」「しっかりと」「積極的に」）
2. 重複する接続表現（「また、」「さらに、」「そして、」の連続。段落の頭にだけ残す）
3. 同じことの言い換え（「使いやすく、ストレスなく利用できる」→ どちらか1つ）
4. 学びの一般化部分（「〜の重要性を学びました。この学びは〜にも活かせます」→ 後半を削る）
5. 背景説明の細部（技術の説明、プロダクトの説明）

## 増やす順序（文字数不足のとき）

感想や意気込みを足さない。足すのは行動の具体。

1. 行動の判断理由（なぜその方法を選んだか）
2. 誰と・どう認識を合わせたか（マネージャー、デザイナー、AI）
3. 成果の数値（正典表にあるもの）
4. 学びが次にどう活きたか（実際に活かした場面があるもののみ）

## インターン向け表現の本選考向け変換表

過去回答はほぼインターン向け。流用するときは必ず変換する。

| インターン向け（過去回答） | 本選考向け |
|---|---|
| インターンでは〜したい | 入社後は〜したい |
| インターンを志望しました | 志望しました／志望理由は〜です |
| 貴社のインターンで | （企業名）で |
| 現在、スタートアップ企業にてiOSエンジニアとして従事しています | 2025年5月から2026年6月まで、スタートアップ企業でiOSエンジニアとして開発に携わりました |
| 開発アルバイトで | 学生インターンとして（文脈により「スタートアップでの開発インターンで」） |
| インターンの経験を通して | これまでの経験を活かし |

## 表記

- 技術名: TCA（初出は「TCA（The Composable Architecture）」）、SPM、SwiftUI、Swift Testing、Swift Concurrency、GitHub Actions、React、FastAPI（「Fast API」と分けない）、Figma。
- 数字: 半角。範囲は「60〜70%」（全角チルダ）。「1か月」（過去回答の「一月」「1ヶ月」は揃える）。
- 記号: 「」で引用・強調、『』は使わない。感嘆符は使わない。
- 絵文字・特殊記号は使わない（フォームの文字数カウントで2文字扱いになることがある）。
